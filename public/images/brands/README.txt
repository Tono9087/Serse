BRAND LOGOS DIRECTORY
======================

Place official brand logos in this folder.
Logos will automatically be rendered on BrandCards across the catalog and brands pages.

Naming Convention:
------------------
- File names must strictly match the brand slug: `<slug>.svg` or `<slug>.png`
- The system first attempts to load `/images/brands/<slug>.svg`.
- If not found, it falls back to `/images/brands/<slug>.png`.
- If neither exists, a clean typographic text fallback is rendered automatically.

Image Specifications:
---------------------
- Preferred formats: Vector SVG (.svg) or high-resolution PNG (.png) with transparent background.
- Dimensions: Approximately 300x150 px or larger (centered, preserving aspect ratio).
- Content: Official brand logos only. Do not invent or distort brand marks.
